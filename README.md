# codespace-practice

## The Last File in the Repository

Mira opened the codespace at 3 a.m. and found a single file waiting for her.

`README.md`. Eleven lines. Two headings, a sentence about a first experiment, and the
words *codespace experiment* repeated like someone knocking on a door to see if anyone
answered.

She had inherited the repository from a colleague who had left three weeks earlier, and
the commit log held just two entries: one that added a file, and one that renamed it.
That was the whole history. Whatever grand experiment had been planned, it had ended
before it began.

Mira opened a terminal and considered her options. She deleted the file. The directory
went quiet and empty, and for a moment she felt the clean, weightless relief of a
cleared desk.

Then she undid it.

Not because the story was good, she told herself later, but because deleting someone's
only remaining work felt worse than leaving it unfinished. Some things, she decided, are
allowed to be small.

She typed a single line and saved. The codespace hummed. Somewhere far away, a machine
she couldn't see accepted the change, and the file was no longer the last one — it was
the first one that came after.
